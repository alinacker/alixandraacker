# Research Paper Thumbnails

This folder contains thumbnail images for the research papers displayed on the Research page.

## Required Images

Please add the following thumbnail images to this folder:

1. **paper1.jpg** - Thumbnail for "AI-CRISPR as Epistemic Arbiter..."
2. **paper2.jpg** - Thumbnail for "Grounding Kenya's Agritech Success..."
3. **paper3.jpg** - Thumbnail for "Negotiating the Nile..."

## Image Specifications

- **Format:** JPG, PNG, or WEBP
- **Recommended dimensions:** 800x500 pixels (16:10 aspect ratio)
- **File size:** Keep under 500KB for optimal performance
- **Content:** Should represent the research paper visually (charts, diagrams, key concepts, etc.)

## Fallback

If thumbnail images are not provided, the site will fall back to using the default profile picture (ali_pic_v2.jpg).

## Updating Paper Information

To update the research paper details (authors, abstract, venue, year), edit the `researchPapers` array in:
`src/components/Research.js`
